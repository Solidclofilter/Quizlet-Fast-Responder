# If something goes wrong

- **The folder names stacked up past the limit.** Extracting closer to the root of the drive brings the path back in range.
- **Date on the archive looks older than expected.** The archive date is the build date. If a newer one exists, the download page shows it; the latest archive is the current build.
- **Partial extraction leaves the folder incomplete.** Delete the half-extracted folder, extract the zip again into a fresh folder, and start `setup` from there.
- **Antivirus put `setup` in quarantine.** Bring the held copy out of quarantine, then start `setup` from the folder that was extracted.
- **SmartScreen showed up before the window.** On the first launch an unsigned file is the cause. More info and then Run anyway is the path through it.
- **`setup` was carried off without the rest.** Put it back with the other files, or extract the archive another time.
